# تذكيرات الدفع (Payment Reminders)

تذكيرات عبر واتساب لتحصيل الفواتير المستحقة — يدوية (من ملف العميل) وتلقائية
(بقواعد، تُشغَّل يومياً).

## قاعدة العملة

**المبلغ بالدولار (USD) هو المرجع دائماً.** أي قيمة بالشيكل تُعرض تقديرية وفق **أحدث**
سعر صرف (`ExchangeRateService::suggestedRate(today)`) — **وليس** سعر صرف الفاتورة
المتجمّد (`invoice.exchange_rate`).

## التذكير اليدوي

من ملف العميل، تعرض نافذة التذكير: الفواتير المستحقة، إجمالي المستحق (USD)، الرصيد
الدائن غير المخصَّص (USD)، صافي الرصيد (USD)، القيمة التقديرية بالشيكل، وأحدث سعر صرف.
القالب الافتراضي `payment_reminder_manual` بالعربية ويتضمن `{{customer_name}}`,
`{{balance_usd}}`, `{{balance_ils}}`, `{{invoice_list}}` — وهو قابل للتحرير قبل الإرسال.

## القواعد التلقائية

جدول `payment_reminder_rules`: `name`, `offset_days`, `timing_type`
(BeforeDue/DueDate/AfterDue), `template_id`, `is_active`, `send_time?`.

الأمر:

```
php artisan payments:send-reminders [--date=] [--dry-run]
```

مُسجَّل في المجدول يومياً (09:00).

- تاريخ الإرسال لكل قاعدة = `sendDateFor(due_date)`: قبل بـ N يوماً / يوم الاستحقاق /
  بعد بـ N يوماً.
- **تُتجاهل** الفواتير: مدفوعة/ملغاة/مسودة، أو المتبقي = 0. الفواتير الجزئية تستخدم
  المتبقي (USD).
- **منع التكرار**: الفهرس الفريد `payment_reminder_logs
  unique(invoice_id, reminder_rule_id, due_date)` — كل قاعدة تُطلق مرة واحدة لكل فاتورة
  لكل تاريخ استحقاق حتى لو شُغّل الأمر عدة مرات في اليوم.

كل تذكير يُنشئ صف سجل (`sent/skipped/failed`) ورسالة واتساب مرتبطة (عبر الطابور).
وضع `--dry-run` لا يُرسل ولا يكتب سجلات.

## الصلاحيات

`whatsapp.reminders.view/manage` لإدارة القواعد، و`whatsapp.send` للإرسال اليدوي.
البذور تُنشئ 3 قواعد افتراضية (قبل بـ3 أيام، يوم الاستحقاق، بعد بـ7 أيام).
